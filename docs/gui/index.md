# <img src="/assets/gui.svg" style="display: inline;height: 1.5em;margin: 0;"> TAI GUI

This is the graphical version of Tribes: Ascend Installer, providing a simple, guided installation experience.

<p align="center">
  <img src="/assets/gui-example-game-type.png" class="gui-image" alt="TAI GUI example" />
</p>

There are just four steps to installing Tribes: Ascend:
1. [Download](https://wilderzone.org/games/tribes-ascend) and run Tribes: Ascend Installer.
2. Select the game type ("Modded" is recommended).
3. Choose where to install the game. The default location should be fine.
4. Hit the big ol' "Install" button!

The next pages cover each of these steps in more detail. As always, feel free to [contact us](https://wilderzone.org/transparency#admins) if you have any comments or questions.

---

:::important
`ta-installer-windows.exe` requires [VC Redist](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) and [WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) to be installed on your computer. Whilst it's very likely you already have them, it's possible you will need to install them before running TAI.
:::

:::info
A [command line version of TAI](/cli) is also provided in case you need more control over the installation process.
:::
