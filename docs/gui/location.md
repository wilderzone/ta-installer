# Location

Second, select where you'd like the game files to be installed.

You can select anywhere on your PC, although, locations that require administrator permissions to access may not work correctly.
You may also choose whether desktop shortcuts should be created or not.

<p align="center">
  <img src="/assets/gui-example-location.png" class="gui-image" alt="The Location selector, showing the default installation location on Windows" />
</p>

TAI will inform you if the location you have chosen doesn't have enough free space. If this happens, clear some more space on your PC, or return to the [previous step](/gui/game-type) and select a smaller game type.

<p align="center">
  <img src="/assets/gui-example-location-full.png" class="gui-image" alt="The Location selector, showing a warning that the selected location does not have enough free space" />
</p>
