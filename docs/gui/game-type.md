# Game Type

First, select the game type. There are three to choose from:

| Type     | Description                                                                                                                                                                              |
| :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vanilla  | This will include only the content from the vanilla "Parting Gifts" version of the game.                                                                                                 |
| Modded   | This will include all of the vanilla game content, plus [TAMods](https://www.tamods.org/), CTF routes, and all [community-made maps](https://www.dodgesdomain.com/docs/custommaps/).     |
| Custom   | This will allow you to choose exactly which DLC assets you'd like to install.                                                                                                            |

Shown beneath each option is the download size, and the installed size.

## Custom

When the "Custom" game type is selected, an "Edit" button will appear.

<p align="center">
  <img src="/assets/gui-example-game-type-custom.png" alt="The Game Type selector, with the Custom option selected, showing the Edit button" />
</p>

This allows you to select exactly the content you'd like to install.

<p align="center">
  <img src="/assets/gui-example-asset-selection-1.png" alt="The DLC asset selector, with all content selected" />
</p>

Some content is required for the game to run properly, and cannot be deselected. Required content is marked with a grey checkbox, whereas optional content is marked with a blue checkbox.

<p align="center">
  <img src="/assets/gui-example-asset-selection-2.png" alt="The DLC asset selector, demonstrating the visual difference between required and optional content" />
</p>

Use the "OK" button to confirm your selection.
