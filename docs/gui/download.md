# Download

<iframe src="https://wilderzone.org/games/tribes-ascend/embedded" class="ta-download-frame"></iframe>

The installer is just 23MB, so it should download in no time at all.

Then open it, and proceed to the [next step](/gui/game-type)!


## Windows

We don't have a publisher certificate for this application yet, so you might see a warning when you run the installer.

<p align="center">
  <img src="/assets/windows-smart-screen-1.png" class="gui-image" alt="The Windows Smart Screen dialog" />
</p>

If this is the case, select "More info" and then "Run anyway".

<p align="center">
  <img src="/assets/windows-smart-screen-2.png" class="gui-image" alt="The Windows Smart Screen dialog, with the Run Anyway button visible" />
</p>


## Linux

On Linux you may encounter a similar security hurdle.

<p align="center">
  <img src="/assets/linux-run-prevention-dialog.png" class="gui-image" alt="The Linux run-prevention dialog" />
</p>

If this is the case, right click the application and select "Properties".

<p align="center">
  <img src="/assets/linux-context-menu.png" class="gui-image" alt="The Linux context menu, with the Properties option highlighted" />
</p>

In the following dialog, enable "Executable as Program".

<p align="center">
  <img src="/assets/linux-file-properties-executable.png" class="gui-image" alt="The Linux file properties menu, with the Executable as Program option enabled" />
</p>

Then open `ta-installer-linux.run` again.
